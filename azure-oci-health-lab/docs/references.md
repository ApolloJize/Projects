# Reference material

- [Tharseo/DC Health architecture](https://docs.oracle.com/en/solutions/tharseo-data-platform-on-oci/index.html): inspiration for the data bridge; not a claim this is the customer's source code.
- [GoldenGate supported technologies](https://docs.oracle.com/en/cloud/paas/goldengate-service/ocigg/whats-supported.html): source/target support and deployment types.
- [GoldenGate Azure SQL MI example](https://docs.oracle.com/en/cloud/paas/goldengate-service/ocigg/quickstarts/replicate-data-from-azure-sql-managed-instance-to-atp.html): two-deployment replication pattern.
- [SQL Server CDC preparation](https://docs.oracle.com/en/database/goldengate/core/26/coredoc/prepare-preparing-database-oracle-goldengate-cdc-capture.html): TRANDATA and coordinated CDC cleanup.
- [GoldenGate IAM setup](https://docs.oracle.com/en/cloud/paas/goldengate-service/ocigg/create-oracle-cloud-resources.html): deployment resource principals and password secrets.
- [SQL MI connection types](https://learn.microsoft.com/en-us/azure/azure-sql/managed-instance/connection-types-overview): Proxy mode and private SQL connectivity.
- [SQL MI Entra directory permissions](https://learn.microsoft.com/en-us/azure/azure-sql/database/authentication-aad-directory-readers-role): directory-read grants for managed identities.
- [OIC private endpoints](https://docs.oracle.com/en-us/iaas/application-integration/doc/private-endpoints.html): private outbound adapter access.
- [OCI Python GenAI inference client](https://docs.oracle.com/en-us/iaas/tools/python/latest/api/generative_ai_inference/client/oci.generative_ai_inference.GenerativeAiInferenceClient.html): chat API.
- [OCI Terraform provider 7.21.0 source](https://github.com/oracle/terraform-provider-oci/tree/v7.21.0): pinned resource schemas.
- [AzureRM Terraform provider 4.23.0 source](https://github.com/hashicorp/terraform-provider-azurerm/tree/v4.23.0): pinned Azure resources.
